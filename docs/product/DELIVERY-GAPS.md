The first priority now includes a reproducible candidate-pool collection and
review workflow (`RETRIEVAL-REVIEW.md`). Its builder reviews are development evidence;
they cannot be promoted to independent validation. Next changes must be driven by
the observed failures, with the original trials retained.

Definition of completion: code and production acceptance for the promised scope,
reproducible useful artifacts for each supported journey, and explicit remaining
data/quality limits. User validation stays a separate state until actual trials.
Healthy deployments and passing tests do not satisfy all of those criteria.
